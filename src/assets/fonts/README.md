# Bundled fonts

All bundled fonts are under the SIL Open Font License 1.1. Each license file
keeps the font's own copyright line. The `.woff2` files come from the
[Fontsource](https://fontsource.org) packages listed below (Arabic and Latin
subsets only), and `src/styles/fonts.css` declares them.

| Font | Package | Files | License |
| --- | --- | --- | --- |
| IBM Plex Sans Arabic (default) | `@fontsource/ibm-plex-sans-arabic` | `ibm-plex-sans-arabic-*` (300, 400, 500, 600) | `OFL.txt` |
| Cairo | `@fontsource-variable/cairo` 5.3.0 | `cairo-*-wght-normal` (variable, 200–1000) | `OFL-cairo.txt` |
| Tajawal | `@fontsource/tajawal` 5.3.0 | `tajawal-*` (300, 400, 500, 700) | `OFL-tajawal.txt` |
| Readex Pro | `@fontsource-variable/readex-pro` 5.3.0 | `readex-pro-*-wght-normal` (variable, 160–700) | `OFL-readex-pro.txt` |
| Noto Naskh Arabic | `@fontsource-variable/noto-naskh-arabic` 5.3.0 | `noto-naskh-arabic-*-wght-normal` (variable, 400–700) | `OFL-noto-naskh-arabic.txt` |
