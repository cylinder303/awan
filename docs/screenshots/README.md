# Screenshots

Images used by the main README. Each one shows the real app UI in Arabic and
English across a few themes, three windows side by side (the mini mode image
shows several mini timers on a desktop background).

| File | What it shows |
| --- | --- |
| `timer.png` | The Timer page: idle, running with a task, and a short break |
| `mini-mode.png` | Mini timers in different sizes and themes, one translucent |
| `history.png` | Totals, the 7-day chart and the session list |
| `goals.png` | Weekly goal, optional daily goal and past weeks |
| `settings.png` | Timer and sound settings, shortcuts, backup |
| `themes.png` | The theme picker and two of the themes |

To use your own screenshot instead, replace a file and keep its name
(`Win + Shift + S` captures part of the screen on Windows).
